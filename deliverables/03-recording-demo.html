06 / FROM A DEMO TO A TESTABLE METHOD

          
通过对照实验评估方法效果。

          

            评估方案：对比主体单独运行和主体加辅助验证，观察候选质量、复核时间与资源开销。
          

        

        

          

            

              
                

                  对照组
                  加入的机制
                  要回答的问题
                

              
              
                

                  A / PRIMARY
                  完整主体审计工作流
                  候选质量、覆盖与复核成本如何？
                

                

                  B / ASSISTED
                  主体＋按需 CodeQL-AI
                  疑难判断是否获得额外验证？
                

                

                  C / REFERENCE
                  单独 CodeQL（外部参照）
                  两种发现方式各覆盖哪些问题？
                

                

                  D / ABLATION
                  分别移除角色、反证或辅助验证
                  各项机制的独立贡献是什么？
                

              
            

          

          

            

              01
              

                
固定代码、模型和预算

                

                  锁定代码快照、规则、模型版本、算力与 token
                  预算。历史信息按任务时间范围提供。
                

              

            

            

              02
              

                
同时观察收益与代价

                

                  统计候选准确性、已知基准检出情况、任务耗时、内存与人工复核成本。
                

              

            

            

              03
              

                
记录失败、超时与重试

                

                  经验误匹配、符号超时、跨线程建模失败都要记录。失败案例与成功案例同样进入评估。
                

              

            

          

        

        

          评估重点主体发现了哪些问题，辅助检查查清了哪些条件，以及完成这些工作花了多少时间和资源。
