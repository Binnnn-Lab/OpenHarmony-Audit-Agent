# 交互演示前端

**以讲解原理为主的新版入口：[demo.html](demo.html)**。八章节故事式演示、逐步展开的 Parcel 案例、交互约束实验和讲解提示，使用一个 HTML 文件即可离线呈现。详见 [演示说明](DEMO.md)。

本文以下保留原有操作型工作台说明，入口为 `index.html`。

纯 HTML / CSS / JavaScript，无安装、构建、CDN、密钥或网络 API 依赖。只包含手工构造的抽象演示案例，不调用 CodeQL、模型或符号执行引擎。

在仓库根目录运行：

```shell
python scripts/serve_demo.py
```

访问 http://127.0.0.1:8765。默认仅监听本机，且只提供 `frontend/` 内文件；按 Ctrl+C 停止。也可直接用浏览器打开 `frontend/index.html`。

## 三分钟演示顺序

1. **审计工作台**：点击“播放审计过程”，展示 7 个阶段、事件日志和逐步归档的 12 份模拟证据。支持暂停、重置、逐步前进或点击任意阶段跳转。
2. **候选切换**：比较 Parcel 长度边界、Native 清洗函数、NAPI 生命周期三种案例。筛选会联动详情，点击证据标签可以查看结构化记录。
3. **原理实验室**：点击架构节点解释工具分工。开关证据审核条件，展示 STATIC_ONLY、CONFIRMED、REJECTED、NEEDS_EVIDENCE 的差异。改变模型置信度不会改变结论。
4. **证据档案**：查看来源与候选引用，按案例筛选。导出 JSON 只包含当前已回放的模拟证据。
5. **演示报告**：下载随当前进度生成的中文 Markdown。未到决策阶段的候选保持 PENDING。原理实验室的开关实验不会污染案例报告。

右上角“专注演示”可隐藏侧栏以适应投屏。页面兼容桌面与手机，支持键盘操作、弹窗 Escape 关闭和减少动画偏好。

## 与后端的边界

本页面是方法与交互演示，未与 Python 后端接通。证据审核实验展示方法规则，**并非 `evaluate_candidate` 的逐行镜像**。后端已检查候选归属、决定性反证及确定性复核所需字段；原始产物真实性、证据适用范围与哈希仍需调用方核验。页面的 CONFIRMED 仅表示用户选择了实验条件，不代表执行了任何验证。主体从源码调查开始，CodeQL-AI 按需提供辅助材料。

所有位置都是 `abstract/` 下的虚构路径；没有真实 CVE、漏洞材料或实验指标。`oh-demo-001` 是样例标识，不是代码 commit。没有来源时间、实际模型版本或内容哈希的字段保持空值，不伪造运行凭证。装饰性柱形不表达性能数据。

后续接入应以服务端证据校验与 Decision 为准，前端负责展示；不从模型 confidence 推导漏洞结论。

## 可选浏览器检查

运行演示不需要 npm。开发者若需重复执行浏览器回归检查，先启动上述本地服务，确保已安装 Chrome，再在 `frontend/` 运行：

```shell
npm install
npm test
```

测试依赖 `puppeteer-core`，不会下载浏览器。非标准 Chrome 安装位置可设置 `CHROME_PATH`；服务端口改变时可设置 `DEMO_URL`。检查覆盖阶段回放、案例筛选、弹窗、四态证据审核、模型置信度独立性、报告下载，以及 390 / 768 / 1440 像素下的页面布局。
