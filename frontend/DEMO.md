# HTML 原理与流程演示

推荐入口：[demo.html](demo.html)。它是一份自包含的 HTML 讲解稿，样式、图形、案例数据和交互脚本全部内嵌，可直接双击离线打开。也可运行 `python scripts/serve_demo.py`，打开 http://127.0.0.1:8765/demo.html。

已有的操作型工作台保留在 [index.html](index.html)。两个入口各自独立。

运行依赖、安装命令、输入输出和故障处理见 [HTML 工具使用说明书](manual.html)。HTML 为可操作演示材料，DEMO 视频文件尚未录制；说明书末尾提供录制提纲。

## 讲解顺序（建议 5–8 分钟）

1. **从一条告警开始**：提出问题——什么样的证据才能支持一个可信结论？
2. **两个工具如何协作**：点击四个节点，讲清工作流负责组织与调度，CodeQL-AI 负责补充证据。统一候选包串起交接。
3. **跟随 Parcel 案例**：五次推进依次展示静态路径、不变量、候选冻结、反证和静态结论。代码高亮与证据卡同步变化。
4. **亲手改变路径约束**：设定 `n=96`、容量 `64` 展示危险条件；把 n 改成 32，说明安全样例不能证明整个输入域安全；开启完整容量检查，说明路径条件和危险条件的冲突。
5. **独立复核与四态结论**：展示盲验证如何隔离预期结论；点击四张卡解释不同证据组合支持的结论范围。
6. **经验反馈**：点击三个环节，说明候选经验、正反例回归和限定范围复用的区别。
7. **检验方法**：展示基线、对照与消融设计，解释效果需要实际数据支持。
8. **总结**：说明统一编排、证据审核和经验复用的关系。

## 操作

- 底部箭头或键盘 `←` / `→`、PageUp / PageDown 推进；第三章会先推进案例小步骤，再换章节。
- 点击章节数字可跳转，URL `#chapter-1` 至 `#chapter-8` 可直接定位。
- `N` 切换讲解提示，`F` 切换全屏，`Escape` 收起提示并暂停自动播放。
- 自动播放每 9 秒推进一步；切换浏览器标签时暂停。拖动实验输入或手动导航也会暂停。
- 输入控件保留其原生键盘行为；减少动画偏好会关闭视觉动画。
- 单独复制 `demo.html` 即可分享讲解内容；结尾通往旧工作台的附录链接仅在同目录存在 `index.html` 时有效。

## 真实性边界

本演示不调用模型、CodeQL、SMT 求解器或真实程序。约束实验实际在浏览器枚举 `0…256` 的整数玩具域，容量固定为 64；展示结果仅由该模型产生。没有执行内存复制，也没有真实漏洞、CVE、性能指标或设备结果。

容量检查被假定为完整且支配全部复制路径；忽略整数溢出、别名、并发与其他分支。真实符号执行需要显式约束、模型校验和覆盖范围说明。单一路径 UNSAT、超时或 UNKNOWN 不代表组件安全。

证据审核和经验状态展示目标方法设计，尚未接入 Python 后端。候选包中的版本、来源和检查状态均明确为示意，不充当真实运行凭证。实验设计章节提出后续验证方案，效果仍需实际测量。

## 检查

可选测试：在 `frontend/` 安装开发依赖后执行 `npm run test:demo`（需要本机 Chrome；非标准路径可设置 `CHROME_PATH`）。测试直接打开磁盘上的 HTML，无需启动服务器，覆盖章节、案例推进、约束边界、回归环节、键盘和响应式布局。
