# 录屏网页与逐页讲稿

## 使用文件

- deliverables/03-recording-demo.html：用于录屏的单文件网页，内含环境说明和完整讲稿。
- deliverables/03-narration.html：单独打开的讲稿阅读页。
- deliverables/03-narration.md：可编辑讲稿。
- deliverables/03-recording-kit.zip：上述文件及打开说明的打包版本。

将 HTML 保存到电脑后，使用 Chrome、Edge、Firefox 或 Safari 打开。演示的样式、图形、脚本和阅读内容都在文件内部。单独复制演示 HTML 到其他电脑，同样可以离线使用；适用于 Windows、macOS 和 Linux 上的现代浏览器。

## 录制顺序

讲稿与八页演示一一对应，完整录制约 10–12 分钟。正文直接朗读，绿色框是操作提示。推荐 1920×1080 或 1440×900、浏览器缩放 100%，录屏选择演示窗口。

1. 封面介绍主体工具，打开“环境与操作”讲解依赖、安装和命令。
2. 查看任务拆分、角色协作、辅助回写、检查点保存与恢复、整体架构。
3. 按五个步骤展开 Parcel 教学案例：输入、容量、候选、保护条件、独立复核。
4. 点击 96、32、96，再开启容量检查，观察路径条件变化。
5. 点击四种结论，说明对应材料和后续工作。
6. 点击经验登记、正反例回归和经验复用三个环节。
7. 介绍主体与增强版的对照评估方案。
8. 介绍主体、辅助检查和经验复用的分工，结束录屏。

## 网页操作

- 点击底部章节数字可跳转；方向键、PageUp / PageDown 可翻页。
- 第三页有五个步骤，点击“展开下一步”推进。
- 第四页有 32 / 64 / 96 快捷按钮，也可拖动滑块。
- N 打开本页操作提示，F 全屏，Escape 关闭阅读窗口或提示。
- 顶部“环境与操作”和“逐页讲稿”打开内嵌阅读内容，点击“返回演示”回到当前页。
- “重新演示”恢复初始状态。自动播放每 9 秒推进一步，录屏时可按自己的语速手动点击。

## 示例设定

页面采用 Parcel 长度检查教学案例，通过浏览器状态变化展示角色交接和检查点恢复。容量实验在 0–256 的整数输入中检查路径条件与越界条件。第七页为评估方案。

原工作台继续保留在 index.html。主体工具的完整操作说明见 manual.html。

## 更新和检查

在仓库根目录运行：

```shell
node scripts/build_recording_bundle.cjs
python scripts/package_recording.py
```

修改讲稿源文件 frontend/NARRATION.md 或环境说明 frontend/RECORDING-GUIDE.md 后，用上述命令同步到独立演示文件。

在 frontend 目录 npm ci 后执行 npm run test:demo。检查会将独立 HTML 复制到临时空目录，验证内嵌说明与讲稿、章节、证据交接、恢复、输入边界、快捷按钮、键盘及响应式布局。
